大肥鱼语音网关

把语音识别、DeepSeek 和语音合成连接起来。更改保存后立即用于下一次对话。

配置页面仅本机可访问。密钥保存在本机项目目录中，不会在页面回显；空着密钥输入框会保留已保存的值。请勿将配置文件分享或上传。

1 · 语音识别 ASR

推荐：硅基流动 TeleSpeechASR，默认地址和模型已填好，填写硅基流动 API Key。

2 · DeepSeek 对话

默认地址和模型已填好，输入自己的 API Key 即可。

3 · 语音合成 TTS

推荐：硅基流动 CosyVoice2，默认地址、模型和音色已填好，可使用与 ASR 相同的 API Key。

4 · 开发板连接

开发板需要通过 Wi-Fi 访问这台电脑的网关。更改监听地址或端口后请重启网关。

设备地址格式：http://电脑的局域网IP:8080/voice。在设备的 menuconfig 中填写该地址和相同令牌。公网使用请通过 HTTPS 反向代理。
